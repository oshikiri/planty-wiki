# Planty-wiki Documentation

planty-wiki is a lightweight, local-first note-taking app that runs in the browser.
It supports Markdown notes, wiki links, backlinks, folder import/export, offline use, and Cloud Sync across authorized devices.
Notes are stored in an OPFS-backed SQLite database.
