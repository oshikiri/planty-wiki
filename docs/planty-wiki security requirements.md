# セキュリティ要件

## URLとルーティング

- `window.location.hash`などブラウザーのロケーションAPIへ利用者の入力を渡すときは、`/pages/`などプレフィックスのスラッシュを保ったまま、各セグメントにencodeURIComponentを適用してパストラバーサルやXSSを防止する。

## パスの正規化

- Wikiリンクや入力パスを扱うときは、normalizePath相当のロジックで`.`や`..`を解決し、常にルート起点の安全なパスだけを保存・遷移させる。

## 外部入力の検証

- Markdownインポートなど外部ソースから取り込むパスも、必ずnormalizePathを通して検証し、危険な相対パスや制御文字を拒否する。
