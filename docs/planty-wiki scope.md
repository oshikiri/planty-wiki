# 実装範囲

## 初期版

- 初期版は、認証やCloud Syncを持たない、単一ブラウザー内で完結するローカル利用を対象とする。
- 初期版では、複数端末間の同期と競合解決を対象外とする。
- 初回起動にはネットワーク接続を必要とする。初回起動が正常に完了した後は、オフラインでもアプリを起動してローカルのノート機能を利用できるようにする。
- 初期版では、画像と添付ファイルを対象外とする。
- 初期版では、アプリ全体のインストール機能を提供しない。初回オンライン起動後のオフライン起動に必要な最小限のアプリリソースをキャッシュする。

## 将来対応

- Cloud Syncは、ローカル版の要求を満たした後に別段階で実装する。
